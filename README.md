# NumPy Student Marks Analysis

## Project Overview

This project demonstrates the use of NumPy for performing basic statistical analysis on student marks.

A NumPy array is created containing the marks of students, and important statistical measures are calculated using NumPy functions.

## Objective

The main objective of this project is to understand how NumPy can be used efficiently for numerical analysis and statistical calculations.

## Technologies Used

- Python
- NumPy
- Jupyter Notebook

## Dataset

The project uses a simple array containing student marks:

78, 85, 92, 67, 74, 88, 95, 81, 69, 90

## Operations Performed

The following statistical values are calculated:

1. Mean
2. Median
3. Maximum
4. Minimum
5. Standard Deviation

## NumPy Functions Used

- `np.array()` - Creates a NumPy array.
- `np.mean()` - Calculates the average value.
- `np.median()` - Calculates the middle value.
- `np.max()` - Finds the maximum value.
- `np.min()` - Finds the minimum value.
- `np.std()` - Calculates the standard deviation.

## Results

- Mean: 81.9
- Median: 83.0
- Maximum Marks: 95
- Minimum Marks: 67
- Standard Deviation: Approximately 9.01

## Conclusion

This project demonstrates how NumPy simplifies numerical and statistical calculations. Using NumPy functions, different statistical measures can be calculated efficiently from a student marks dataset.
